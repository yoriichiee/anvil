Check packs

A pack adds checks for a stack you use. Packs are plain JSON: text patterns, page and DOM checks, read-only GET and HEAD probes on your own site, and human checklists. A pack cannot run code. Every pack is reviewed in a pull request before it is listed, and a published version never changes.

    Write a pack

    Found a bug Anvil missed? Turn it into a check.

    Each pack is one anvil-addon.json file. Its format is published as a JSON Schema, and CI checks every pull request: the schema, patterns that could hang the scanner, probes limited to GET and HEAD, and versions that never change once released.

    A check that looks for a page or feature only runs when that page or feature is there. If it isn't, the report lists the check under “not checked” instead of failing it.
