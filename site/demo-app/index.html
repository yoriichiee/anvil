Acme Notes

This is the small notes app that Anvil scans in the recorded demo. It has bugs left in on purpose, so Anvil has something real to find.

The real app is a Node server with a JSON API, sign-in and roles. A static site can't run that, so these pages are snapshots: the app's own HTML and CSS, filled in with its seed data. Nothing saves, and there is no sign-in. To run the real thing, clone the repo and start examples/acme-notes.

  • Team notes, as a memberOpen this on a phone: the page scrolls sideways (the table is 820px wide).
  • Shared with me, as a guestThe hero image has no alt text.
  • Workspace settings, as an adminOpen the browser console: an error is logged on every load.

Two bugs can't be shown here: on the real server, a member gets 200 from GET /api/settings instead of 403, and a fake payment key is served in /assets/js/billing.js. The recorded demo shows the evidence for both.
