Install guide · version 0.2.0

Install Anvil

You need Node 20 or later, and Chrome or Edge. If neither browser is found, Anvil offers to download Chromium for you.

1Install

Mac or Linux

$curl -fsSL https://anvil.horvans.com/install.sh | sh

Windows (PowerShell)

PS>irm https://anvil.horvans.com/install.ps1 | iex

The installer downloads anvil-0.2.0.tgz, checks it against SHA256SUMS, runs npm i -g on that local file, and copies the Anvil skill to ~/.claude/skills/anvil. It never installs a "latest" version. Read install.sh or install.ps1 before you run it.

2Connect your agent

Claude Code

$claude mcp add anvil -- anvil-mcp

Codex

$codex mcp add anvil -- anvil-mcp

Both start the binary you just installed. Then ask your agent: “Run Anvil on my app at localhost:3000 and walk me through the human checks.”

3Scan

A running app on your machine

$anvil scan http://localhost:3000

A project folder

$anvil scan ./my-app

Results go to .anvil/runs/<time>/: report.json, report.html, fix-brief.md, prompts for Lovable, Cursor and Claude, and screenshots.

?Just try it

No install, one run

$npx -y https://anvil.horvans.com/dl/anvil-0.2.0.tgz scan http://localhost:3000

?A site that isn't on your machine

Anvil only scans a remote URL after you prove you own it. Without proof it scans localhost only. Run the command below, put the token it prints in /.well-known/anvil.txt on your site, and run it again.

$anvil verify-owner https://your-app.example

?If something fails

This prints your Node, browser and Anvil versions with keys, tokens and paths redacted, ready to paste into an issue.

$anvil doctor --share

Open an issue on GitHub

AI is optional. With no key, every check still runs and the fix brief is written from templates. With your own key, it is stored in your system keychain (or read from an environment variable), and repo text is redacted before it is sent. If redaction fails, nothing is sent.
